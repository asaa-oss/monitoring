# Парсер постов (VK & Telegram)

Скрипт для сбора постов из социальных сетей ВКонтакте и Telegram с последующим сохранением в базу данных и выводом через веб-интерфейс.

---

## 1. Настройки подключения (Секретные ключи)

Для работы скрипта создайте файл `.env` в корневой папке проекта и добавьте в него ваши доступы:

```env
# ВКонтакте (VK)
TOKEN=ваш_токен_доступа

# Telegram (my.telegram.org)
api_id=ваш_api_id
api_hash=ваш_api_hash
```

### ⚠️ Важные инструкции по получению ключей:
* **Telegram (`api_id` и `api_hash`):** Получаются на сайте [my.telegram.org](https://telegram.org/apps). *Обратите внимание: сайт капризный, может потребоваться несколько попыток или использование VPN/инкогнито при авторизации.*
* **ВКонтакте (`TOKEN`):** Можно получить через сервис [vkhost.github.io](https://vkhost.github.io). При переходе по ссылке авторизации в поле настроек прав (`scope`) обязательно укажите: `wall,offline`.

## 2. Структура базы данных (SQLite)

> 🚨 **ВАЖНО:** Самого файла базы данных в репозитории нет! Перед запуском скрипта вам необходимо **вручную завести пустой файл** с именем `links.db` в корне проекта. Если вы назовете его иначе, обязательно поменяйте название файла `.db` в конфигурации вашего кода (раздел `databases` переменная DB_FILE, (если назвали 'my_db' например то пишите 'my_db.db'. .db в конце обязательно добавьте)).

После создания пустого файла `links.db` запустите файл 'db_create.py'. файл создаст таблицы в бд.
опять же если назвали файл не `links.db` - в файле db_create.py поменяйте значение переменной db на ваш файл (С РАСШИРЕНИЕМ! НЕ 'program' а 'program.db' )

## 💡 Важные примечания по запуску и разработке

### Подсветка ошибок в VS Code (Jinja)
При работе с шаблонами фронтенда редактор VS Code может подсвечивать синтаксис как ошибочный. **Не обращайте на это внимания.** Это ложные срабатывания, связанные с особенностями интеграции шаблонизатора **Jinja**. Код полностью рабочий.

### Первый запуск Telegram-модуля
Перед запуском основного приложения **обязательно** выполните в терминале команду:
```bash
python tg.py
```
В терминале появится запрос на ввод данных вашего Telegram-аккаунта (номер телефона и код подтверждения). Это необходимо для авторизации и генерации локального файла `.session`. После однократного ввода сессия сохранится, и скрипт будет работать автоматически в фоновом режиме.
### 🔧 Модификация библиотеки Telethon (Важно!)

Для корректной работы Telegram-модуля требуется небольшое ручное исправление в исходном коде библиотеки `telethon`. 

В исходном классе `TelegramBaseClient` (от которого наследуется используемый в коде `TelegramClient`) изначально **отсутствует** атрибут `http_session`. Для исправления возможных ошибок инициализации сессии выполните следующие действия:

1. Откройте файл с исходным кодом базового клиента в вашей виртуальной среде (путь обычно выглядит так: `.venv/lib/python3.X/site-packages/telethon/client/telegrambaseclient.py`).
2. Найдите метод инициализации `__init__`.
3. добавьте в аргументы http.session = 'None' (значение по умолчанию none . в коде нужное значение само определится
)
4. Вручную добавьте объявление атрибута `http_session` в тело класса:
   ```python
   self.http_session = http_session # Добавьте эту строку в метод __init__
   ```
Без этого исправления модуль `tg.py` может выбрасывать `AttributeError` при попытке обращения к HTTP-сессии.

### Запуск приложения 
для запуска приложения запустите файл main.py . Для теста исключительно вк- main_vk.py
для исключительно тг - main_tg.py. После в терминале  наберите uvicorn (название_файла):app --reload. После того как появилась надпись Application startup complete саму страницу найдите по адресу http://localhost:8000.
